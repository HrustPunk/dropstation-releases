# Dropstation — Windows releases

Локальное приложение для управления просмотром Twitch, игровыми Drops и баллами канала. Тёмная панель, отдельные аккаунты и сохранённые браузерные сессии.

## Скачать

Откройте [список релизов](https://github.com/HrustPunk/dropstation-releases/releases) и скачайте **Dropstation.exe** для Windows x64. Python не требуется; нужен установленный Chrome или Edge. SHA-256 каждого файла указан в `SHA256SUMS.txt` соответствующего релиза. Предварительные версии помечены `Pre-release`; цифровой подписи пока нет.

## Обновления

Начиная с alpha.6: **Настройки → Обновления → Скачать → Перезапустить и установить**. Проверка выполняется также в фоне. Новая сборка сохраняет прежнюю папку данных, настройки и сессии аккаунтов. До установки можно продолжать работу. Если новая версия не запустится, приложение попытается вернуть предыдущий EXE.

Сборки до alpha.6 нужно один раз заменить вручную. Данные находятся отдельно, по умолчанию в `%LOCALAPPDATA%\Dropstation\data`.

## Что публикуется здесь

Этот репозиторий содержит только готовые сборки, контрольные суммы и описания изменений. Исходники развиваются отдельно. Пользовательские базы, пароли, сессии, журналы и реальные снимки аккаунтов в релизы не включаются. Не публикуйте свою папку данных.

Значки Twitch пока доступны для изучения условий; их автоматическое получение не включено. Приложение не оформляет подписки, не тратит баллы и не отправляет сообщения в чат. Наличие плеера само по себе не подтверждает начисление награды: прогресс и получение проверяются по ответам Twitch.
